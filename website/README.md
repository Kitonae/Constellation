# Constellation Website

This directory contains the marketing and downloads site for Constellation.

Stack:
- Vite
- React
- TypeScript
- Tailwind CSS

## Development

```powershell
cd website
npm ci
npm run dev
```

## Build

```powershell
cd website
npm run build
```

## Lint

```powershell
cd website
npm run lint
```

The deployment workflow in `.github/workflows/deploy.yml` builds this directory.
